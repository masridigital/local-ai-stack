# Deploy checklist

Do not put PHI on this stack until Marko has cleared the build and every line below is true. The Anthropic switch ships **off**.

1. VM is Ubuntu Server LTS, LUKS is up, `/var/lib/local-ai-stack` is on that volume.
2. `deploy/install.sh --apply` has been run (or `ansible-playbook -i ansible/inventory.ini ansible/site.yml`). cloudflared is not installed. `ss` shows no public listen except SSH from the VPN, and Caddy only on `127.0.0.1` or `VPN_BIND_IP`. Presidio, the gateway, and Postgres are on `127.0.0.1`. LiteLLM is on `127.0.0.2:4000`. `scripts/check_luks.py --target /var/lib/local-ai-stack` succeeded.
3. UFW default deny incoming and outgoing. Owner rules match `deploy/ufw/owner.rules`. The Open WebUI REJECT is ahead of the loopback accept, and TCP/8088 on `127.0.0.1` and `127.0.0.2` rejects every uid except `openwebui` before that accept. `egress-proxy.service` listens on `127.0.0.1:8888` (Open WebUI, Entra only), `127.0.0.1:8889` (LiteLLM), `127.0.0.1:8890` (apt, named hosts only), and `127.0.0.1:8891` (policy gateway, configured MCP hosts only). nftables rejects every other uid on those ports before the loopback accept. `api.anthropic.com` is absent unless `ANTHROPIC_BAA_ENABLED=true`. `AZURE_API_HOST` is one label whose name includes a US region from `litellm/policy.yaml` and ends in `.openai.azure.com`. Confirm with the checks in `docs/egress-proxy.md`, including reboot persistence, DHCP, IPv6 neighbor discovery, and a non-owner uid.
4. Credential files exist, mode 0600, root-owned, under `/etc/litellm`, `/etc/policy-gateway`, `/etc/open-webui`, and `/etc/postgres`: Postgres password, database URL, audit URL, LiteLLM master key, scoped LiteLLM virtual key (gateway only), Azure API key (`/etc/litellm/azure_api_key`), Open WebUI secret, bootstrap admin password, Entra client secret, and the gateway client key (Open WebUI and the gateway). There is no Azure client secret on the LiteLLM unit. The Anthropic key exists only when `ANTHROPIC_BAA_ENABLED=true`. `install.sh` does not write `/etc/cloudflared/credentials.json`, and there is no `/etc/cloudflared` directory. `MICROSOFT_CLIENT_ID` is not the zero GUID.
5. **ZDR.** `anthropic_zdr_confirmed_by_cap` is true. Cap attested in chat on 2026-10-15 ("BAA has ZDR"). Formal document verification is still pending at Cap's 8 AM review. Before `ANTHROPIC_BAA_ENABLED=true`, confirm in the Anthropic console that this exact API key and organization are the HIPAA org covered by the BAA and that zero data retention is on for that org. Record the date and the org id in the evidence pack. A key from another org stays blocked.
6. Foundry deployment name is set in `AZURE_OPENAI_DEPLOYMENT`. The deployment is Azure OpenAI, Microsoft-hosted, family `gpt-4.1` or `gpt-4o` (including the mini/nano ids in the policy). It is not an `azure_ai/` marketplace model.
7. Abuse-monitoring / human-review opt-out is unchanged unless Cap already has written approval. Do not flip `FOUNDRY_ABUSE_MONITORING_OPT_OUT` on a guess.
8. Entra app uses PKCE (`S256`). Open WebUI’s tenant variable is `MICROSOFT_CLIENT_TENANT_ID` (`f7812296-5bce-41dc-8102-b1b270e7c4c7`). Do not set `AZURE_TENANT_ID` on Open WebUI. Redirect `https://webui.lan.internal/oauth/microsoft/callback`. Enterprise app **Assignment required = Yes**, scoped only to the `PHI-users` group. App roles are `phi`, `non-phi`, and `admin`. The `admin` role is assigned only to `local-ai-admins`. Local signup is off. OAuth signup remains only for people already in `PHI-users`. The password form is off. The bootstrap account is not a sign-in path. Conditional Access requires MFA. Admin sign-in is phishing-resistant, with an 8-hour sign-in frequency. Tools and Functions are admin-only.
9. The user-id pilot gates in `docs/residual-risk.md` are true: only the `openwebui` uid can open TCP/8088, a missing gateway user id is rejected, audit rows store email and id, and the gateway client key was rotated if `local-ai-admins` changed since the last apply.
10. A synthetic prompt (the fixture MRN, not real PHI) is masked in the audit row and the row has no raw identifier.
11. Backup restore has a scheduled owner and a quarterly date. Break-glass secret is in the vault, not on the disk in cleartext beyond the sealed file used during an incident.
12. `deploy/check-password-login.sh --live` prints `password login is refused`. sshd refuses password authentication, and Open WebUI sign-in answers HTTP 403.
13. After the first Entra admin has signed in, `scripts/retire_bootstrap_admin.py --require` has run. The bootstrap row is `pending`, its password hash is null, and `/etc/open-webui/webui_admin_password` is empty.
14. `scripts/capture_admin_role.py` wrote `/var/lib/local-ai-stack/evidence/local-ai-admins-role.json` with `"assigned": true` for group `local-ai-admins` and role `admin`. The Graph token is not in that file.
15. Gateway health is probed with `deploy/health-check.sh gateway`, which runs `curl` as the `openwebui` uid. The LiteLLM `:4000` probe stays root because that uid is rejected from port 4000.
